# Roadster / Flight Lab

Three.js 夜间试车场概念游戏。使用简化运动模型，并非真实车辆或飞行性能模拟。

## 运行

```sh
pnpm install
pnpm dev
```

打开终端显示的本地地址。`pnpm build` 构建生产文件。

默认循环自动演示。点击「接管驾驶」开始挑战：按 W 加速，通过坡道时按住 Shift 吸附；出坡道后用上下方向键把车头转正，左右方向键翻滚，空格喷气。落在绿色区域并保持车身正立即成功。R 重试，C 切换视角。

吸附仅在坡道上有效；喷气消耗储气。为保证可玩性，坡道运动受轨迹约束，空中使用简化重力与推力积分，未使用完整轮胎或空气动力学模型。

驾驶按键会退出自动演示并从起点开始手动挑战。必须在坡道需要吸附的部分持续按住 Shift，完整通过倒挂段才具备通关资格；中途失去吸附后，即使喷气并落入目标区也不算成功。手动喷气沿车身上方施力，倒置时会向下推。

回归检查：`node --test src/*.test.js`。

绿色区域边界与通关边界一致，要求整车触地后停稳在线内。黄色标记为按当前姿态和喷气输入估算的触地点（后续操作会改变预测），青色标记保留实际触地点。

自动演示支持「暂停 / 继续」按钮或 P 快捷键；暂停冻结模拟，可用 C 切换观察视角。驾驶按键接管时会从起点开始手动挑战。

移动端竖屏仅观看，横屏解锁多指触控驾驶：加速/制动、吸附锁定、姿态摇杆、喷气与左右平移。驾驶中转为竖屏会清空输入并回到演示。

支持简体中文和英文。默认浏览器语言，手动选择会保存；?lang=en 或 ?lang=zh 可指定进入语言。当前页面语言与浏览器首个受支持的偏好不同则提示切换，用户可关闭提示（本次会话不再重复），不会强制跳转。
